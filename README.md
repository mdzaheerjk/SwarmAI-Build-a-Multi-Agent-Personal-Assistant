# SwarmAI-Build-a-Multi-Agent-Personal-Assistant
Build an AI personal assistant using a multi-agent architecture to manage email, calendar, research, and travel planning. It integrates real APIs and runs via web, Telegram, and voice interfaces, powered by n8n workflow automation.
